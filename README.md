打开上面的网页即可游玩，不需要下载代码或 ZIP。登录入口仅用于游戏进入操作，公开仓库中的源码与素材仍可直接访问。

公开的手机竖屏互动回忆游戏：React + TypeScript + PixiJS + Vite。

## 使用

`npm ci` 安装依赖，`npm run dev` 本地运行，`npm run build` 构建网页。GitHub Actions 自动发布到 GitHub Pages。

本仓库包含经所有者确认公开的游戏故事与照片、视频、音乐素材。公开静态站点不提供服务器密码保护，素材可被直接访问。素材仅用于本人的游戏展示，公开仓库不代表授予第三方再分发权利。

仓库不包含整个工作目录、微信助手、登录凭据或真实密码。
